# Codex Notes

Use this file to record project-specific guidance for working in this repository.

- Prefer small, targeted Rust changes that keep Milestone 0 buildable.
- Use `mise run` to launch the app during development.
- Run `mise test` after editing config, input, or app-state code.
- Use the `mise test` task instead of calling `cargo test` directly.
- Keep new files limited to what the current milestone actually needs.
